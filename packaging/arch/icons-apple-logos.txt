# Apple-logo removal list for the composed icon theme grassfield-icons (owner decision 2026-10-23, ADR-0017).
# Input of packaging/arch/icons-compose.py. One entry per line:
#   <layer>:<path in the upstream checkout> [kind]
#   mactahoe:src/<category>/<size>/<file>      pebble:Pebble/<dir>/<dir>/<file>
#   kind: apple-logo (default) | finder-face | doubt | appstore
# apple-logo, finder-face and doubt: the file's whole icon NAME is dropped from that layer (every size, every directory)
# with every link that resolves to one of them; the name falls through to the next layers (Pebble, our glyphs, Breeze,
# Adwaita, hicolor). doubt: the owner's rule "in doubt, Pebble" (an unclear mark, or an App Store glyph: the store comes
# from Pebble). appstore: a MacTahoe file whose names are served by Pebble's shopping bag instead.
# Every listed file must exist at the pinned commit (the composer fails on pin drift). Re-derive on a pin change.
#
# Source: by-eye sweep of contact sheets of EVERY regular file of both pins (MacTahoe 839848b: 11,631 files on 117
# sheets; Pebble 185da58: 4,882 files on 49 sheets; five reviewers, 2026-10-23), with zoomed renders of devices,
# screens and windows and the integrator's check of each hit and doubt; then a second, automatic pass: every path of the
# listed logo files was drawn alone, the 23 that draw the apple were kept as position-free signatures (the path data
# after its first moveto) and every regular file of both pins was searched for them (3 more files found and added:
# accessories-system-cleaner twice, Pebble's preferences-system-windows); last, the independent review of the merge
# found a byte-for-byte Pebble copy of a listed Finder face and an Apple-logo raster hidden in an SVG (both added; the
# composer now refuses any copy of a listed file and checks embedded and PNG rasters). Only the Apple logo (and the
# Finder face, Apple's
# mark for its file manager) is removed; look-alikes of Apple app icons stay (owner: "pour le reste je prends le risque").
