# Fingerprints of the Apple-logo glyph paths found in the pinned upstream themes (ADR-0017, owner decision 2026-10-23).
# Input of packaging/arch/icons-compose.py (default next to it; --signatures FILE overrides). The composer fails when
# any regular SVG of the composed theme draws a path whose signature has one of these SHA-256 values, so a logo that a
# pin change or an alias brings back cannot ship.
# Signature of a path: its `d` data with runs of white space collapsed to one space, trimmed, and the first moveto
# (`M x y` / `m x y`) removed, so the same glyph placed elsewhere in an icon has the same signature. Only hashes are
# stored here: the repository holds no Apple artwork.
