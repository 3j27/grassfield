# Internationalization (gate I1)

English is the source language; French (`fr`) is the first translation. Every visible string is wrapped in
`qsTr()` (QML/JS) or `tr()` / `QT_TRANSLATE_NOOP` (C++). Quickshell has no built-in translation loading, so
Grassfield ships its own.

## Runtime

- QML module `Grassfield.I18n` (`ui/i18n/`, C++ extension plugin). Singleton `Translator`:
  - on first use picks the language from `GRASSFIELD_LANG` (dev override, e.g. `fr`), else `QLocale::system()`
    (LC_ALL / LC_MESSAGES / LANG); `C` means English;
  - loads `grassfield_<lang>.qm` (`fr_FR` falls back to `fr`) from `$GRASSFIELD_TRANSLATIONS_DIR`, else
    `/usr/share/grassfield/translations`, installs it on the application and re-evaluates every `qsTr()` binding
    through `QQmlEngine::retranslate()`;
  - sets `QLocale` default to the language so dates and `Qt.locale()` follow it;
  - exposes `language` (writable: live change) and `retranslate()`;
  - exposes `formats` (writable: `region.formats`, Settings > General > Language & Region): with a locale name such as
    `fr_CH` the default `QLocale` becomes the language in that region (English + `fr_CH` = `en_CH`: Swiss formats, English
    day and month names, as macOS keeps the words of the language), or that region's own locale when Qt has no such pair
    (French + `en_US`: `en_US`) (`formatsLocale()` in `translationloader.h`, the contract's localeName pattern, anchored;
    `General.formatsLocale` in Settings is the same rule for its preview); "auto" or anything else is the language's. A
    language change keeps the chosen formats. Bindings with a `qsTr()` pattern follow at once (`retranslate()`), the others at their
    next evaluation (a clock's tick). `tests/shell/i18n_live`.
- `shell/shell.qml` reads `Translator.language` first so the catalog is installed before any surface evaluates strings,
  and binds `Translator.formats` to `Settings.regionFormats`: the menu bar clock, the widgets and the lock screen format
  with the chosen region. The apps (Files, Preview) keep the language's formats.
- The three apps call `grassfield::i18n::installForApplication()` (`ui/i18n/translationloader.h`, the same loader
  the plugin uses, R5) in `main()` before creating the engine.
- No catalog (or English) leaves the source strings; missing translations also fall back to English.

## Catalog

- One catalog: `translations/grassfield_fr.ts`, generated by `scripts/dev/i18n-update.sh` (`just i18n-update`):
  `lupdate -no-obsolete -locations none` over `shell/ ui/ apps/`. Line numbers are omitted so unrelated edits
  never make the catalog stale. Plurals use explicit strings (`1 item` / `%1 items`), not `%n`.
- `scripts/dev/i18n-build.sh` compiles to `.dev/translations/*.qm` (dev). Packaging builds the same files with
  CMake (`ui/i18n/CMakeLists.txt`, `qt_add_lrelease`) into `/usr/share/grassfield/translations`; the module goes to
  `/usr/lib/qt6/qml/Grassfield/I18n` (see `packaging/arch/PKGBUILD`).
- Dev wiring: `ui/i18n/build-direct.sh` builds the module into `.dev/build/qml`; `scripts/dev/shell-run.sh` adds it
  to `QML_IMPORT_PATH` and sets `GRASSFIELD_TRANSLATIONS_DIR=.dev/translations`. Try it with
  `GRASSFIELD_LANG=fr scripts/dev/nested-up.sh`.
- One translation per source string (context-specific overrides are possible by editing the `.ts` directly;
  `lupdate` preserves them).

## Gate: `just check-i18n` (part of `just check`)

`scripts/dev/check-i18n.py` fails when (a) the catalog is stale against the code, (b) any French message is
unfinished, (c) a QML/JS visible-text property (`text`, `placeholderText`, `title`, `label`, `subtitle`,
`caption`, `hint`, `tooltip`, `Accessible.name`, `Accessible.description`, `ToolTip.text`, ...) is assigned a bare
string literal containing letters. A deliberate exception carries `// i18n-ignore` on the same line.

## Session helpers (`packaging/bin`)

The helpers that send notifications (`grassfield-crash-watch`, `-battery-watch`, `-session-end`, `-migrate-notify`) are
standard-library scripts and cannot load Qt's `.qm` catalogs. Each carries its own French table: a `CATALOG["fr"]` dict keyed
by the English source string and a `tr()` (Python), or the `fr:` cases of `tr` (bash). The language is `GRASSFIELD_LANG`, else
`LC_ALL`, `LC_MESSAGES`, `LANG`, as the shell's Translator picks it. The gate (`scripts/dev/check-i18n.py`, part e) fails when
such a helper has no French table, passes `tr()` a string without a French text (or the same text, or other `%` placeholders),
or puts a bare English literal in a `notify-send` argument list. Tests that read the English text pin `LC_ALL=C`.

## French naming (no Apple trademarks, §14)

French follows macOS French UI conventions for generic phrases (« Forcer à quitter… »,
« Suspendre l'activité », « Éteindre », « Redémarrer », « Placer dans la corbeille ») with typographic
punctuation (non-breaking space before `: ; ? ! %` and inside « »). Feature names:

| English | French | Note |
|---|---|---|
| Overview / Desktops | « Vue d'ensemble » / « Bureaux » (one: « Bureau 2 ») | renamed 2026-10-18 (owner decision), was "Spaces"; avoids Apple's French feature names |
| Glance | « Survol » | Apple's French name for its quick preview is not used |
| Preview (app) | « Visionneuse » | « Aperçu » is Apple's French app name |
| Search | « Recherche » | |
| Apps | « Apps » | |
| Notifications / Quick Settings | « Notifications » / « Réglages rapides » | renamed 2026-10-18 (owner decision), were "Notification Center" / "Control Center" |
| Settings app | « Réglages Grassfield » (menu: « Réglages… ») | renamed 2026-10-18 (owner decision), menu was "System Settings…" / « Réglages Système… » |
| Do Not Disturb | « Ne pas déranger » | renamed 2026-10-18 (owner decision), was "Focus" |
| Screen Corners | « Coins de l’écran » | renamed 2026-10-18 (owner decision), was "Hot Corners" / « Coins actifs » |

## Adding a string

Wrap it in `qsTr()`, run `just i18n-update`, translate the new `<translation type="unfinished">` entries,
run `just check`.
